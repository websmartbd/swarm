Made to run on pages you already have

Swarm reads the page as it is in the browser, so there is no export step and nothing to prepare.

One script tag

Add swarm-plugin.js and a small button appears on the page. There is nothing to build or configure.

Rebuilds the real page

Text, images, icons, form fields and backgrounds are read from your live DOM and rebuilt piece by piece.

Keeps motion alive

Endless animations such as orbits, spinning rings and floating cards are copied with their motion and fade in as the build reaches them.

Scroll, or take the tour

Agents build what is on screen. Scroll to keep going, or press Tour and let the page scroll itself.

Sound, if you want it

Finished pieces can play a soft piano note. Toggle it with the speaker button or the M key.

Safe to try

It runs in an isolated overlay. Press Esc or Go live and your real page is right where you left it.

How it works

  1. Step 1

    Add the script

    Place one tag before the closing body tag. Swarm adds a faint button to the side of the screen.

  2. Step 2

    Start the effect

    Click the button, call Swarm.start(), or run it automatically on page load.

  3. Step 3

    Watch it build

    Cursors scan the page, then lay down every element. When they finish, Go live returns you to the real page.

Install in one line

Paste this single script tag before </body>.

<script src="https://bmshifat.pro.bd/assets/js/swarm-plugin.js"></script>

Options

Set these as data- attributes on the script tag.

data-position middle-right Where the button sits: top, middle or bottom, with left, center or right.
data-opacity 0.35 Resting opacity of the button. Solid on hover and focus.
data-button true Set to false to remove the button and trigger Swarm yourself.
data-autostart false Run the effect as soon as the page loads.
data-accent #00f3ff Colour of the button's hover glow.

Or control it via JS

Trigger Swarm from any element or script:

<button data-swarm> HTML trigger
Swarm.start() Start
Swarm.stop() Stop
Swarm.toggle() Toggle

Questions

Does it change my site? +

Swarm draws a copy of the page in an isolated overlay. Your own markup and styles stay as they are, and Esc closes the overlay.

What can it not rebuild? +

Iframes appear as labelled placeholders. Canvas and video show a still frame when the browser allows it.

Can I start it from my own button? +

Yes. Add data-swarm to any element, or call Swarm.start(). Set data-button="false" if you do not want the built-in one.
